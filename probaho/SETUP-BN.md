# Probaho — সেটআপ গাইড (বাংলা)

## যা লাগবে
- PHP **8.0 বা নতুন** (cPanel → *Select PHP Version*) — এক্সটেনশন: `pdo_mysql`, `openssl`, `curl`, `mbstring`, `gd`, `fileinfo`
- MySQL / MariaDB ডাটাবেস
- **SSL (HTTPS)** — Passkey, Push নোটিফিকেশন ও অ্যাপ ইনস্টলের জন্য বাধ্যতামূলক (cPanel → *SSL/TLS Status* → AutoSSL)

## ধাপ ১ — ফাইল আপলোড
1. cPanel → **File Manager** → `public_html` (অথবা যে ফোল্ডারে চালাতে চান) খুলুন।
2. `probaho.zip` আপলোড করে **Extract** করুন।
3. `probaho` ফোল্ডারের **ভেতরের সব ফাইল** `public_html`-এ সরিয়ে দিন (ডোমেইনের মূলে চালাতে চাইলে)।
   সাব-ফোল্ডারে (যেমন `example.com/pay`) চালাতে চাইলে ফোল্ডারটির নাম বদলে সেখানেই রাখুন — অ্যাপ নিজে থেকেই পাথ বুঝে নেবে।
4. লুকানো ফাইল দেখান (*Settings → Show Hidden Files*) এবং নিশ্চিত হন যে `.htaccess` ফাইলগুলো আছে।

## ধাপ ২ — ডাটাবেস তৈরি
cPanel → **MySQL Databases**:
1. নতুন ডাটাবেস তৈরি করুন (যেমন `user_probaho`)।
2. নতুন ইউজার ও শক্ত পাসওয়ার্ড তৈরি করুন।
3. ইউজারকে ডাটাবেসে যুক্ত করে **ALL PRIVILEGES** দিন।

> ডাটাবেস ফাঁকা রাখুন — টেবিল ইনস্টলার নিজেই তৈরি করবে।

## ধাপ ৩ — ফোল্ডার পারমিশন
এই ফোল্ডারগুলো **755** (লেখার অনুমতি) হতে হবে: `config/`, `storage/`, `storage/cache/`, `storage/logs/`, `uploads/`

## ধাপ ৪ — ইনস্টলার চালান
ব্রাউজারে খুলুন: `https://আপনার-ডোমেইন/install`
1. সব রিকোয়ারমেন্ট "ঠিক আছে" দেখাচ্ছে কি না দেখুন।
2. ডাটাবেস হোস্ট (সাধারণত `localhost`), নাম, ইউজার, পাসওয়ার্ড দিন।
3. সাইটের URL দিন (যেমন `https://pay.example.com`) এবং **"সবসময় HTTPS ব্যবহার করুন"** টিক দিন।
4. প্রথম অ্যাডমিনের নাম, ইমেইল ও পাসওয়ার্ড (১০+ অক্ষর) দিন → **ইনস্টল করুন**।

ইনস্টল শেষে `/install` স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যায়।

## ধাপ ৫ — অ্যাডমিন প্যানেলে কনফিগার করুন
লগইন: `https://আপনার-ডোমেইন/v2admin/login`

| মেনু | কী করবেন |
|---|---|
| **সেটিংস → সাধারণ / ব্র্যান্ডিং** | সাইটের নাম, লোগো, ফেভিকন, রঙ, যোগাযোগ, কারেন্সি |
| **SMTP ইমেইল** | হোস্ট, পোর্ট (587=TLS / 465=SSL), ইউজার, পাসওয়ার্ড, From — তারপর **টেস্ট ইমেইল** পাঠান |
| **সাপোর্ট** | Telegram ও WhatsApp নাম/নম্বর/লিংক, কাজের সময় |
| **Binance Pay** → সেটিংস ট্যাব | Manual মোড: আপনার Binance Pay ID দিন। API মোড: Merchant API Key + Secret |
| **পেমেন্ট মেথড** | bKash / Nagad / ব্যাংক ইত্যাদি যোগ করুন (নির্দেশনা, ফি, সীমা) |
| **সার্ভিস / প্রোডাক্ট / পোস্ট / FAQ / পেজ** | কনটেন্ট যোগ ও সম্পাদনা |
| **AI নলেজ বেস** | চ্যাটবট যে তথ্য দিয়ে উত্তর দেবে |
| **সেটিংস → অথেন্টিকেশন** | Google লগইন, Passkey, রেজিস্ট্রেশন, ইমেইল ভেরিফিকেশন, 2FA |
| **সেটিংস → AI সহকারী** | বিল্ট-ইন (API ছাড়া) অথবা Claude / অন্য API key |
| **PWA / Web Push / সিকিউরিটি** | ইনস্টল প্রম্পট, পুশ, সেশন টাইমআউট, CAPTCHA, পাসওয়ার্ড নীতি |
| **অ্যাডমিন** | নিজের অ্যাকাউন্টে **2FA চালু করুন** (প্রস্তাবিত) |

## Google লগইন চালু করা
1. https://console.cloud.google.com → *APIs & Services → Credentials → Create OAuth client ID* (Web application)।
2. **Authorized redirect URI:** `https://আপনার-ডোমেইন/auth/google/callback`
3. Client ID ও Secret অ্যাডমিন → সেটিংস → অথেন্টিকেশনে দিন এবং "Google লগইন" চালু করুন।

## Binance Pay API মোড (ঐচ্ছিক)
Binance Merchant অ্যাকাউন্ট থেকে API Key ও Secret নিন। Webhook URL দিন:
`https://আপনার-ডোমেইন/payment/binance-pay/webhook`

## সমস্যা হলে
- **৫০০ / খালি পেজ:** PHP ভার্সন ৮+ কি না এবং এক্সটেনশন চালু কি না দেখুন। বিস্তারিত ত্রুটি: `storage/logs/`
- **পেজ 404 আসে (হোম ছাড়া):** `.htaccess` আপলোড হয়েছে কি না দেখুন; সাব-ফোল্ডারে থাকলে `.htaccess`-এ `RewriteBase /ফোল্ডার/` চালু করুন।
- **ইমেইল যায় না:** অ্যাডমিন → লগ → ইমেইল লগে ত্রুটি দেখুন; হোস্টিংয়ের SMTP পোর্ট খোলা কি না যাচাই করুন।
- **Passkey/Push কাজ করে না:** সাইট অবশ্যই HTTPS-এ চলতে হবে।
- **ব্যাকআপ:** `config/config.local.php` ফাইলটি সংরক্ষণ করুন — এতে এনক্রিপশন কী আছে।
