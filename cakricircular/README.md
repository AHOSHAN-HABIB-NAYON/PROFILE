# চাকরি সার্কুলার (cakricircular.com) — Node.js + MySQL

বাংলা চাকরির খবর, ভর্তি, রেজাল্ট, নোটিশ ও স্কলারশিপের সাইট। একটাই Node প্রসেস চলে (শেয়ার্ড হোস্টিং উপযোগী), ইন-অ্যাপ শিডিউলার আছে, cron ঐচ্ছিক।

## Hostinger এ প্রথমবার ইনস্টল

1. **ডাটাবেজ:** hPanel → Databases → MySQL Databases থেকে একটি ডাটাবেজ ও ইউজার তৈরি করুন (নাম, ইউজার, পাসওয়ার্ড লিখে রাখুন)।
2. **Node.js অ্যাপ:** hPanel → Websites → Node.js (বা "Setup Node.js App")
   - Node version: **18 বা তার বেশি** (২০/২২ ভালো)
   - Application root: এই `cakricircular` ফোল্ডার
   - Entry file / Startup file: `server.js` (অথবা `app.js`)
3. ফাইল আপলোড/ডিপ্লয় করুন, তারপর **npm install** চালান (প্যানেলের বাটন বা `npm install --omit=dev`)।
4. অ্যাপ চালু করে ব্রাউজারে ডোমেইন খুলুন → স্বয়ংক্রিয়ভাবে **/install** পেজ আসবে।
5. ডাটাবেজের তথ্য, সাইটের নাম, এডমিন ইউজার/পাসওয়ার্ড ও **গোপন এডমিন পথ** (ডিফল্ট `v2admin`) দিন → "ইনস্টল করুন"।

ইনস্টলার কনফিগ (`config.json`), গোপন কী ও আপলোড ফোল্ডার রাখে কোড ফোল্ডারের **বাইরে**: `~/.cakricircular/`।
তাই পরে নতুন ফাইল ডিপ্লয় করলে **আর কোনো তথ্য দিতে হবে না** — ডাটাবেজ স্কিমা আপডেট (migration) অ্যাপ চালুর সময় নিজে থেকেই হয়।

> অন্য ফোল্ডারে রাখতে চাইলে এনভায়রনমেন্ট ভ্যারিয়েবল `CC_DATA_DIR=/path` দিন।

## আপডেট করা

নতুন ফাইল আপলোড / git pull → `npm install` → অ্যাপ রিস্টার্ট। ব্যাস। কনফিগ, আপলোড করা ছবি/PDF, লোগো থেকে বানানো অ্যাপ আইকন — সব আগের মতো থাকবে।

## এডমিন প্যানেল

`https://আপনার-ডোমেইন/v2admin` (সেটিংস → সিস্টেম থেকে পথ বদলানো যায়)।
পোস্ট, ক্যাটাগরি, ব্যানার, বিজ্ঞাপন, নোটিশ, রিপোর্ট, অটোমেশন, অ্যানালিটিক্স, পেজ ও টিম, সাবস্ক্রাইবার, ইউজার/পারমিশন, সেটিংস।
সেভ করলেই ক্যাশ পরিষ্কার হয়ে সাইটে সাথে সাথে পরিবর্তন দেখা যায়।

পুরোনো PHP সাইটের `$2y$` bcrypt পাসওয়ার্ড হ্যাশ সরাসরি কাজ করে (প্রথম লগইনে স্বয়ংক্রিয়ভাবে নতুন ফরম্যাটে আপগ্রেড হয়)।

## অটোমেশন

অটোমেশন পেজে OpenAI API key, মডেল, সোর্স সাইট (WordPress) URL দিয়ে চালু করুন।
ধাপ: স্ক্র্যাপ → AI ছাড়া যাচাই (নতুন/পরিবর্তিত/ডুপ্লিকেট/মেয়াদোত্তীর্ণ/রাউন্ডআপ) → শুধু নতুনগুলো OpenAI → **খসড়া** হিসেবে সেভ (কখনো নিজে প্রকাশ করে না) → এডমিনকে মেইল।
লক থাকায় একসাথে দুইবার চলে না; ১০ মিনিট সাড়া না দিলে লক নিজে মুক্ত হয়।

ঐচ্ছিক cron (Hostinger → Advanced → Cron Jobs), অটোমেশন পেজে দেখানো লিংক দিয়ে:

```
*/30 * * * * curl -s "https://আপনার-ডোমেইন/cron/run?key=XXXX" >/dev/null
```

## ইমেইল

সেটিংস → ইমেইল: Hostinger মেইলের জন্য সাধারণত `smtp.hostinger.com`, পোর্ট `465`, SSL। "পরীক্ষামূলক মেইল পাঠান" দিয়ে যাচাই করুন।

## লোকাল ডেভেলপমেন্ট

```bash
npm install
CC_DATA_DIR=./data PORT=3000 npm run dev    # তারপর http://localhost:3000/install
```

## টেস্ট

```bash
npm test
# ইন্টিগ্রেশন টেস্টের জন্য একটি খালি MySQL ডাটাবেজ লাগবে:
TEST_DB_NAME=chakri_test TEST_DB_USER=... TEST_DB_PASS=... npm test
```

ইউনিট টেস্ট: বাংলা সংখ্যা/তারিখ/স্লাগ, ডুপ্লিকেট শনাক্তকরণ, HTML স্যানিটাইজ, `$2y$` পাসওয়ার্ড, আপলোড যাচাই।
ইন্টিগ্রেশন টেস্ট: ইনস্টলার, পেজ ও ক্যাশ, লগইন রেট-লিমিট, CSRF, ছবি কম্প্রেশন, স্লাগ রিডাইরেক্ট, আপলোড সুরক্ষা, সার্চ/সাইটম্যাপ/ম্যানিফেস্ট, রিপোর্ট রেট-লিমিট, মেইনটেন্যান্স মোড, মক WordPress + মক OpenAI দিয়ে পুরো অটোমেশন, cron কী, বাল্ক অ্যাকশন, রিস্টার্টের পর কনফিগ থাকা।

## ফোল্ডার কাঠামো

```
server.js            অ্যাপ এন্ট্রি (app.js = একই)
src/config.js        কোডের বাইরের কনফিগ
src/migrate.js       অটো ডাটাবেজ মাইগ্রেশন
src/routes/          পাবলিক সাইট ও ইনস্টলার
src/admin/           এডমিন প্যানেল (auth, routes)
src/automation/      স্ক্র্যাপ → AI → খসড়া পাইপলাইন
src/views/           HTML টেমপ্লেট (সার্ভার-রেন্ডার)
src/scheduler.js     ইন-অ্যাপ শিডিউলার
public/              CSS, JS, সার্ভিস ওয়ার্কার, আইকন, ফন্ট
test/                টেস্ট
```
