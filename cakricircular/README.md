# চাকরি সার্কুলার — CakriCircular

Core PHP + MySQL দিয়ে তৈরি, কিন্তু চলে React/Next.js অ্যাপের মত — এক পেজ থেকে অন্য পেজে গেলে পুরো পেজ রিলোড হয় না, শুধু মূল কনটেন্ট AJAX দিয়ে বদলায়।

## সেটআপ (৪ ধাপ)

1. সব ফাইল হোস্টিং-এর `public_html` (বা ডোমেইন রুট) এ আপলোড করুন।
2. `config/config.php` খুলে ডেটাবেজ তথ্য বসান:
   ```php
   define('DB_NAME', 'আপনার_ডিবি');
   define('DB_USER', 'আপনার_ইউজার');
   define('DB_PASS', 'আপনার_পাসওয়ার্ড');
   ```
   ডেটাবেজ তৈরির সময় Collation দিন **utf8mb4_unicode_ci** (বাংলার জন্য জরুরি)।
3. ব্রাউজারে `https://yourdomain.com/install.php` খুলুন → এডমিন ইউজারনেম ও পাসওয়ার্ড দিন → ইনস্টল।
4. ইনস্টল শেষে **install.php ফাইলটি সার্ভার থেকে মুছে ফেলুন**।

এডমিন লগইন: `https://yourdomain.com/v2admin`
(এডমিন সেটিংস থেকে এই গোপন পথ যখন খুশি বদলানো যায়)

ফোল্ডার পারমিশন: `uploads/` এবং এর সব সাব-ফোল্ডার **755** (বা প্রয়োজনে 775)।

## ফাইল স্ট্রাকচার

```
index.php              সব রিকোয়েস্টের একমাত্র দরজা (রাউটার + লেআউট)
.htaccess              ক্লিন URL, ক্যাশ, সিকিউরিটি হেডার
install.php            একবারের ইনস্টলার (পরে ডিলিট করুন)
config/
  config.php           ডেটাবেজ ও সাইট কনফিগ
  db.php               PDO সংযোগ (utf8mb4)
  helpers.php          বাংলা সংখ্যা, সময়, স্লাগ, আপলোড+কম্প্রেশন, CSRF, পেজিনেশন
app/
  schema.php           ডেটাবেজ টেবিল
  api.php              /api/track, /api/notices, /api/report
  sitemap.php          /sitemap.xml
  pages/               home, category, post, search, trending, notices, report, info, 404
partials/              header, sidebar, footer, bottomnav, post_card
assets/js/app.js       SPA ইঞ্জিন
admin/                 এডমিন প্যানেলের সব মডিউল
uploads/               banners, posts, pdf, site
```

**প্রতিটি ফাইলের ডিজাইন তার নিজের ভেতরেই** (`css_once()` দিয়ে) — আলাদা কোনো CSS ফাইল নেই। একই CSS দ্বিতীয়বার লোড হয় না, ডুপ্লিকেট ইভেন্ট লিসেনারও তৈরি হয় না।

## যা কাজ করে

- পেজ বদল AJAX-এ, Header/Navbar/Sidebar/Footer একবারই লোড
- History API — Back/Forward বাটন সম্পূর্ণ কাজ করে, প্রতিটি URL সরাসরি খুললেও চলে
- আগের পেজ ক্যাশ + hover/viewport-এ প্রিফেচ → ক্লিকের সাথে সাথে পেজ আসে
- টপ প্রোগ্রেস বার + ফেড ট্রানজিশন, ছবি lazy load, ছবি ৩০ দিন ব্রাউজার ক্যাশ
- ব্যানার: অটো স্লাইড, সোয়াইপ, তীর, ডট, লিংক (সর্বোচ্চ ১০টি)
- ছবি অটো কম্প্রেস: 1MB→100KB, 2MB→200KB, 3MB→300KB, 4MB→400KB, 5MB→450KB
- আবেদনের বাকি সময় লাইভ কাউন্ট, শেষ হলে "সময় শেষ"
- শেয়ার পপআপ (Facebook, X, WhatsApp, Telegram, লিংক কপি) + সব জায়গায় মেটা কার্ড
- সার্চ পেজে ফিল্টার, টপ সার্চ, রিসেন্ট সার্চ
- নোটিশ ব্যাজ + সাউন্ড, মোবাইল বটম মেনু
- এডমিন: পোস্ট/ক্যাটাগরি/ব্যানার/নোটিশ/রিপোর্ট/সেটিংস, মাল্টিপল ডিলিট, ২য় এডমিন ও মডারেটর পারমিশন, অ্যানালিটিকস (ইউনিক ডিভাইস, লোকেশন, টপ পেজ)
- SEO: Organization + WebSite + JobPosting + NewsArticle + BreadcrumbList schema, ক্লিন URL, sitemap.xml, robots.txt, canonical, OG/Twitter কার্ড
- সিকিউরিটি: PDO prepared statement, CSRF টোকেন, লগইন রেট-লিমিট, আপলোড ভ্যালিডেশন, uploads-এ স্ক্রিপ্ট ব্লক, সেশন হার্ডেনিং, ৪০৪ পেজ

## দুটো কথা খোলাখুলি

- **PDF কম্প্রেশন**: ছবির মত সত্যিকারের PDF কম্প্রেশন PHP-তে শেয়ার্ড হোস্টিংয়ে করা যায় না (Ghostscript লাগে, যা সাধারণত থাকে না)। তাই PDF-এ সাইজ যাচাই ও ১৫MB লিমিট রাখা হয়েছে। বড় ফাইল হলে আপলোডের আগে ilovepdf দিয়ে কমিয়ে নিন।
- **ভিজিটরের লোকেশন**: ip-api.com থেকে আনা হয় (ফ্রি, ক্যাশ করা)। হোস্টিং আউটগোয়িং কানেকশন ব্লক করলে লোকেশন "অজানা" দেখাবে — সেটিংস থেকে বন্ধ করে দিতে পারেন, বাকি সব ঠিক থাকবে।

PHP 7.4 বা তার উপরে, GD এক্সটেনশন চালু থাকতে হবে (প্রায় সব হোস্টিংয়ে থাকে)।
