# Play Console: background location declaration video (30-60 s)

Record on a real phone (child role) with screen recording on. Show, in order:
1. **0-8 s** Parent phone: Family → "Add child" → the 6-letter child code appears.
2. **8-18 s** Child phone: enter the code and first name → the background location page: the animated demo, then the
   prominent disclosure text ("Nirapod collects location data to show your location to your family, even when the app is
   closed or not in use") → tap Continue → the system dialog → choose **Allow all the time**.
3. **18-26 s** Consent page: who can see the location (photos of the parents) → "I understand" → "You're all set".
4. **26-38 s** Child home: the green "Location sharing is on" status and the permanent notification in the status bar.
   Lock the phone, walk a few steps; unlock the parent phone: the child's marker moves on the map.
5. **38-50 s** Child phone: "Who can see me" screen. Parent phone: member page → "Request update now" → the child sees
   "Mom requested your location".
6. **50-60 s** Explain the stop path: a parent removes the device (Family → member → Remove), the notification disappears.

Declaration text: "Nirapod is a family safety app. Background location lets parents see their child's live location,
get arrival/departure alerts and SOS alerts. Sharing is always visible (permanent notification), needs consent, and
location is never sold or used for ads. Staff never see locations."

Foreground service (location type): the same video; the service only runs on child phones while sharing is on.
