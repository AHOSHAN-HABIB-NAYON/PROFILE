About the app

FilePilot is an Android file manager and developer toolkit by Webtecit Apps (developer: MD AHOSHAN HABIB NAYON). It works offline and keeps your files on your device.

  • File manager for internal storage, SD cards and USB drives, with categories, search, favorites and a 30-day Recycle Bin.
  • Code Studio with syntax highlighting, and HTML Studio that runs websites offline with mobile, tablet and desktop previews.
  • Storage Analyzer, Cleaner and duplicate finder.
  • APK information, HEX, SQLite, archive, font and terminal tools.
  • Secure Folder with AES-256 encryption, PIN and fingerprint.
  • PDF viewer, images to PDF, merge and compress PDFs.
