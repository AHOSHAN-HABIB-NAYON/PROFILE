বসানোর পর ঠিক হলো কিনা দেখতে:

```bash
node scripts/check-uploads.js      # নেই এমন ফাইলের তালিকা দেখায়; সব থাকলে "✔ সব ফাইল আছে"
```

> টিপ: আলাদা করে কপি করতে না চাইলে `.env`-এ `UPLOAD_DIR` পুরোনো সাইটের `uploads` ফোল্ডারের পথ দিন
> (যেমন `/home/u123456789/domains/cakricircular.com/public_html/uploads`) — তখন দুই সাইট একই ফাইল ব্যবহার করবে, কপির দরকার নেই।
