# সেটআপ গাইড (cPanel / শেয়ার্ড হোস্টিং)

## যা লাগবে
- PHP 8.1 বা তার উপরে (cPanel → Select PHP Version থেকে 8.1/8.2/8.3 দিন)
- PHP extension চালু রাখুন: pdo_mysql, curl, gd, mbstring, fileinfo
- MySQL ডাটাবেস, SSL (https) চালু থাকা ভালো

## ধাপ ১: ডাটাবেস তৈরি
1. cPanel → **MySQL® Databases**
2. নতুন ডাটাবেস তৈরি করুন (যেমন `user_shop`)
3. নতুন ইউজার তৈরি করুন + শক্ত পাসওয়ার্ড দিন
4. ইউজারকে ডাটাবেসে যোগ করুন → **ALL PRIVILEGES** দিন
5. ডাটাবেস নাম, ইউজার, পাসওয়ার্ড লিখে রাখুন

## ধাপ ২: ফাইল আপলোড
1. cPanel → **File Manager** → `public_html` ফোল্ডারে যান
   (সাবডোমেইনে বসাতে চাইলে সেই সাবডোমেইনের ফোল্ডারে যান)
2. **Upload** → `shop.zip` আপলোড করুন
3. zip ফাইলে রাইট-ক্লিক → **Extract** → `public_html` এ এক্সট্র্যাক্ট করুন
   - খেয়াল রাখুন: `index.php`, `.htaccess`, `assets/` ইত্যাদি সরাসরি `public_html` এর ভিতরে থাকবে, কোনো সাব-ফোল্ডারে নয়
   - `.htaccess` না দেখলে File Manager → Settings → **Show Hidden Files** চালু করুন
4. পুরনো `index.html` থাকলে মুছে দিন
5. `shop.zip` ফাইলটি মুছে দিন

## ধাপ ৩: ফোল্ডার পারমিশন
নিচের ফোল্ডারগুলোর পারমিশন **755** দিন (সাধারণত আগে থেকেই থাকে):
`storage`, `storage/cache`, `storage/logs`, `uploads`

## ধাপ ৪: ইনস্টলেশন উইজার্ড
1. ব্রাউজারে আপনার ডোমেইন খুলুন → স্বয়ংক্রিয়ভাবে **ইনস্টলেশন উইজার্ড** আসবে
2. সার্ভার চেক সবুজ হলে → পরবর্তী
3. ডাটাবেস: হোস্ট `localhost`, পোর্ট `3306`, ধাপ ১ এর নাম/ইউজার/পাসওয়ার্ড
4. অ্যাডমিন ইউজারনেম ও পাসওয়ার্ড দিন (কমপক্ষে ৮ অক্ষর, অক্ষর + সংখ্যা)
5. সাইটের নাম, URL (`https://আপনার-ডোমেইন.com`), WhatsApp নম্বর, ডেলিভারি চার্জ দিন
6. **ইনস্টল করুন** → সফল হলে `/admin/login` এ নিয়ে যাবে
   (ইনস্টলার নিজে থেকেই লক হয়ে যায়)

## ধাপ ৫: অ্যাডমিন থেকে সাজানো
`https://আপনার-ডোমেইন.com/admin/login` এ লগইন করে এই ক্রমে করুন:
1. **সেটিংস → সাধারণ**: লোগো, ফেভিকন, রং
2. **সেটিংস → যোগাযোগ**: ফোন, Facebook, WhatsApp
3. **ক্যাটাগরি** → ক্যাটাগরি যোগ করুন
4. **পণ্য → নতুন পণ্য** → ছবি, দাম, স্টক, সাইজ দিন
5. **ব্যানার**, **কুপন**, **কম্বো** (প্রয়োজন অনুযায়ী)
6. **কুরিয়ার** → Steadfast/Pathao/RedX এর API key দিন → **কানেকশন টেস্ট**
7. **সেটিংস → ফ্রড চেক** → BDCourier API key দিন
8. **সেটিংস → ট্র্যাকিং** → Meta Pixel ID, Access Token, Google Tag (থাকলে)
9. **সেটিংস → PWA ও থিম** → অ্যাপ আইকন আপলোড

## ধাপ ৬: HTTPS বাধ্যতামূলক করা (SSL চালু থাকলে)
`.htaccess` ফাইলে এই দুই লাইনের সামনের `#` মুছে দিন:
```
RewriteCond %{HTTPS} !=on
RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

## সমস্যা হলে
- **৫০০ Error / সাদা পাতা**: PHP ভার্সন 8.1+ কিনা দেখুন; `storage/logs/` ফোল্ডারের লগ দেখুন
- **পেজ খুললে 404**: `.htaccess` আপলোড হয়েছে কিনা দেখুন (Show Hidden Files)
- **ছবি আপলোড হয় না**: `uploads/` পারমিশন 755; cPanel → PHP Options এ `upload_max_filesize` 12M, `post_max_size` 64M দিন
- **আবার ইনস্টল করতে চাইলে**: `.env` এবং `storage/installed.lock` মুছে দিয়ে ডোমেইন খুলুন
- **Cloudflare ব্যবহার করলে**: `.env` ফাইলে `TRUST_PROXY="true"` দিন (সঠিক কাস্টমার IP পেতে)
